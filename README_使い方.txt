サービス設計書 取込ツール 使い方
================================================

■ 同梱物
  設計書取込ツール_テンプレート.xlsx … シート雛形・部品・設定（マクロを入れて .xlsm で保存する）
  DesignImport.bas                 … 取込マクロ（Shift_JIS、VBEインポート用）
  TABS1220                         … 取込ファイルの例（拡張子なし / UTF-8）
  Copilot用プロンプト.txt          … Copilotに取込ファイルを出力させる指示文

■ 初回セットアップ（1回だけ）
  1. 設計書取込ツール_テンプレート.xlsx を開く
  2. Alt+F11 → [ファイル] → [ファイルのインポート] → DesignImport.bas
  3. [ファイル] → [名前を付けて保存] → 「Excel マクロ有効ブック (*.xlsm)」で保存
  4. フローオブジェクトシートに FO_開始・FO_分岐・FO_処理概要・FO_テーブル・FO_線 などの図形が入っている。
     フロー図はこの図形をコピーして描くので、色や形を変えればそのまま反映される。
     ※社内の図形に差し替える場合は、図形を貼って名前ボックスで「FO_開始」等の同じ名前にし、
       文字を「{{テキスト}}」にする（処理概要は {{処理No}} と {{テキスト}}）
     ※図形を消してしまった場合は Alt+F8 →「パレット初期化」で不足分だけ再作成できる

■ 毎回の作業
  1. Copilotに「Copilot用プロンプト.txt」＋例（TABS1220）＋Javaソースを渡す
  2. 出力をメモ帳に貼り、「UTF-8」で拡張子なし（例: TABS1230）で保存
     ※メモ帳の保存時に「すべてのファイル(*.*)」を選ぶと .txt が付かない（.txt付きでも取込可）
  3. ツールで Alt+F8 →「取込ファイル_検証」で書式チェック（任意）
  4. Alt+F8 →「設計書取込_フォルダ一括」→ 取込ファイルを置いたフォルダを選ぶ
     ※フロー図が不要（または図形で止まる）場合は「設計書取込_フォルダ一括_フロー図なし」
       ／「設計書取込_ファイル指定_フロー図なし」を使う。FLOWブロックは読み飛ばし、概要フローシートは見出しのみ
  5. 「入力フォルダ\出力」に サービス設計書_処理ID_処理名.xlsx が1プログラム1ファイルで出力される
  6. 結果・警告は「取込ログ」シートに出る

■ レイアウトを社内の本物に合わせるとき（マクロ修正は不要）
  ・部品シートのブロックが「下へ下へコピーされる単位」。CO列の赤字がブロック名。
      TPL_種別_H   … 見出し（1回）       例 TPL_EDIT_H
      TPL_種別_R   … 明細1行分（行数分）
      TPL_種別_F   … 締め（1回）
      TPL_種別_サブ_H/_R/_F … >サブ名 の部分  例 TPL_ACCESS_JOIN_H
  ・社内の本物のシートから1ブロック分の行をコピーして部品シートに貼り、
    値の入るセルを {{キー}} に書き換え、行範囲の名前を同じ名前に付け直せばよい
    （名前の管理: 数式タブ →「名前の管理」）
  ・（任意）{{>キー}} と書くと「階層」列の値だけ右へずらして書く機能もある（標準の部品では未使用）
  ・{{_NO}} は ①②③…、{{_N}} は 1,2,3…（結合テーブル①などの番号）
  ・ヘッダ（1～3行目）は出力シート雛形のセルに {{処理ID}} 等で書いておけば各シートに入る
  ・新しい種別やサブを増やす場合も、部品を作り名前を付けて、設定シートに 種別→シート を足すだけ
  ・EOL列や右側の変更履歴列も部品に含めたい場合は、設定の「最終列」を増やす
  ・処理定義の SQL箱・エラー表の色は 部品シートの「箱スタイル見本」のセル色で変えられる

■ 編集定義（Entity・Object の I/O 網羅）
  編集定義シートには次の順で出力される
    ・I/O一覧（#BEGIN IOLIST）… 使用する Entity / Dto / Object ごとに I（設定）/ O（参照）と編集名
    ・DAO呼出ごと: IN編集仕様 → SQL入力（Entity→SQLパラメータ）→ SQL出力（SQL結果→Entity）→ OUT編集仕様
    ・SQL以外の詰め替え（>MAP）… Dto→Dto、Entity→Object、戻り値作成 など
  I/O一覧に載っていて編集定義にないもの（備考「要確認」）が、レビューで見るべき箇所

■ 文字コード
  取込ファイルは UTF-8 を推奨（BOMあり/なし両方可）。①や～、外字に近い文字も化けない。
  Shift_JIS で保存したファイルを読む場合は設定シートの文字コードを Shift_JIS にする。
  ※DesignImport.bas だけは VBE の仕様上 Shift_JIS で保存してある（そのままインポートでOK）

■ 注意
  ・数字や日付に見える値（1-1、1.07、2026/11/08 等）は文字列として書き込む（日付化け防止）
  ・フロー図は図形のコピーにクリップボードを使うため、実行中はコピー操作をしないこと
