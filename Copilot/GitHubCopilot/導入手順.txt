GitHub Copilot（VS Code）用 出力命令 導入手順
================================================
1. このフォルダの .github と design-import を、Javaソースのリポジトリ直下にコピーする
   （既に .github/copilot-instructions.md がある場合は中身を追記する）
2. VS Code の設定で「Chat: Prompt Files」を有効にする（chat.promptFiles = true）
3. Copilot Chat を「エージェント」モードにして、
     /design-reverse        … 1プログラム分（起点クラス名を聞かれる）
     /design-reverse-batch  … フォルダ内を一括
     /design-reverse-proc   … 既存ファイルの処理定義だけをメソッド単位で作り直す（省略されたとき）
   と入力する
4. design-import/ に 処理ID の名前（拡張子なし）で取込ファイルができる
5. Excelの設計書取込ツールで「設計書取込_フォルダ一括」→ design-import フォルダを選ぶ
   ※ _example フォルダは中に入っているので対象外（フォルダ直下のファイルだけ取り込む）

ヒント
- 1回に渡すソースが多すぎると精度が落ちる。巨大なServiceはメソッド単位に分けて依頼し、
  出力を1ファイルにまとめてもよい（同じ種別のブロックは何個並べても可）。
- 出力後は Excel 側の「取込ファイル_検証」で書式チェックができる。
